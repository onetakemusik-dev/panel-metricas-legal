# panel-metricas-legal

Páginas públicas (home y política de privacidad) de **Panel de Métricas ADAN**, la
herramienta personal de análisis del canal de YouTube de ADAN.

Existen para cumplir los requisitos de Google Auth Platform (página principal y
política de privacidad en un dominio verificado) y para verificar el dominio en
Google Search Console.

## Contenido

- `index.html` — qué es la app y qué hace (en español e inglés).
- `privacy.html` — qué datos de Google se leen, para qué, dónde se guardan y cómo
  revocar el acceso. Incluye la declaración de *Limited Use*.

## Publicación

Servido con GitHub Pages desde la rama `main`, carpeta raíz. Sitio estático sin
dependencias ni compilación: se edita el HTML y se hace commit.
