Panel de Métricas ADAN

Aplicación personal de análisis que lee en modo solo lectura las estadísticas del canal de YouTube de ADAN para generar reportes internos.

Qué es

Panel de Métricas ADAN es una herramienta de escritorio que corre de forma privada en el ordenador de su autor, dentro de un contenedor Docker. No es un servicio público, no crea cuentas para terceros y no se ofrece como producto a usuarios externos: la usa únicamente el equipo que gestiona el canal, con autorización del propietario del canal.

Qué hace

  • Guarda cada hora una foto de las métricas públicas del canal (suscriptores, vistas y últimos vídeos y Shorts) usando la YouTube Data API.
  • Con el permiso expreso del propietario del canal, consulta la YouTube Analytics API (solo lectura) para ver retención, fuentes de tráfico, países, edad y género.
  • Muestra todo en un panel web local con gráficas por periodos de 24 horas, 7, 30 y 90 días, y una página de auditoría con recomendaciones.
  • Envía resúmenes al equipo por un bot de Telegram que solo responde a los chats autorizados.

Acceso a datos de Google

La aplicación solicita acceso de solo lectura a datos de YouTube y YouTube Analytics. Nunca modifica el canal: no publica, no edita, no borra contenido y no cambia la configuración del canal. Los datos se guardan únicamente en el equipo local del autor y no se comparten con terceros. Todos los detalles están en la política de privacidad.

Uso limitado. El uso que Panel de Métricas ADAN hace de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

ADAN Metrics Panel

A personal analytics application that reads ADAN's YouTube channel statistics in read-only mode to produce internal reports.

What it is

ADAN Metrics Panel is a desktop tool that runs privately on its author's own computer, inside a Docker container. It is not a public service, it does not create accounts for third parties, and it is not offered as a product to external users: it is used only by the team managing the channel, with the channel owner's authorization.

What it does

  • Stores an hourly snapshot of the channel's public metrics (subscribers, views and the latest videos and Shorts) using the YouTube Data API.
  • With the channel owner's explicit consent, reads the YouTube Analytics API (read-only) for retention, traffic sources, countries, age and gender.
  • Displays everything in a local web dashboard with 24-hour, 7, 30 and 90-day charts, plus an audit page with recommendations.
  • Sends summaries to the team through a Telegram bot that only answers allow-listed chats.

Google data access

The application requests read-only access to YouTube and YouTube Analytics data. It never modifies the channel: it does not publish, edit or delete content, and it does not change the channel's settings. Data is stored only on the author's local computer and is not shared with third parties. Full details are in the privacy policy.

Limited Use. ADAN Metrics Panel's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
