Política de privacidad

Última actualización: 8 de noviembre de 2026

Esta política explica cómo la aplicación Panel de Métricas ADAN (en adelante, «la aplicación») accede, usa y almacena datos, incluidos los datos obtenidos de las API de Google.

1. Quién está detrás

La aplicación es un proyecto personal de Napo, desarrollado en la República Dominicana, para la gestión del canal de YouTube del artista ADAN. Responsable del tratamiento y contacto: ONETAKEMUSIK@gmail.com.

2. Datos a los que accedemos

La aplicación solo pide los permisos necesarios para leer estadísticas, siempre en modo solo lectura:

FuenteQué se lee
YouTube Analytics API Con el permiso yt-analytics.readonly: vistas, tiempo de visualización, retención de audiencia, fuentes de tráfico, países, edad, género, suscriptores ganados y perdidos, y desglose por tipo de contenido (vídeos y Shorts).
YouTube Data API v3 Datos públicos del canal y de sus vídeos: título, fecha de publicación, duración, vistas, «me gusta» y comentarios. No se accede a datos privados de los espectadores.

La aplicación no accede a contraseñas, correos electrónicos, contactos, mensajes, archivos, calendario ni a ninguna otra información de la cuenta de Google. Nunca modifica el canal: no publica, no edita ni borra contenido.

3. Para qué se usan

  • Generar reportes internos y gráficas de evolución del propio canal.
  • Producir recomendaciones de contenido y de colaboraciones para el equipo del artista.
  • Enviar resúmenes periódicos al equipo por Telegram, cuando se solicitan.

Los datos no se usan para publicidad, ni para perfilado comercial, ni para entrenar modelos de inteligencia artificial.

4. Dónde se guardan

Los datos se almacenan únicamente en el ordenador del responsable, en una base de datos SQLite dentro de un contenedor Docker local. No se envían a servidores propios, no se alojan en la nube y no se suben a ningún repositorio público. Las credenciales de acceso a Google se guardan en el mismo equipo, en un archivo de configuración local excluido de cualquier copia pública.

Se conservan fotos de métricas cada hora durante 45 días; a partir de ahí, se conserva una foto por día. En cualquier momento se pueden eliminar por completo borrando el volumen de datos de Docker del equipo.

5. Con quién se comparten

No se venden, alquilan ni comparten con terceros. No se usan para publicidad ni para elaborar perfiles de usuarios.

La única salida de datos fuera del equipo es el resumen que el responsable solicita expresamente al bot de Telegram, y que se envía únicamente a los chats del propio equipo que estén en la lista de permitidos de ese bot (un número reducido de personas que gestionan el canal).

6. Seguridad

El panel solo es accesible desde el propio ordenador (red local, con contraseña opcional), el bot rechaza cualquier chat no autorizado y las claves se mantienen fuera del código y fuera de repositorios públicos.

7. Cómo revocar el acceso y borrar los datos

  • Revocar el permiso de la aplicación en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de poder leer datos del canal de inmediato.
  • Solicitar el borrado de los datos almacenados escribiendo a ONETAKEMUSIK@gmail.com. Se eliminan en un plazo máximo de 30 días.

8. Uso limitado de los datos de Google

El uso que Panel de Métricas ADAN hace de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

En concreto: los datos de Google solo se usan para las funciones descritas en esta política, no se venden a terceros, no se usan con fines publicitarios, no se usan para determinar solvencia ni para préstamos, y ninguna persona puede leerlos salvo el responsable del proyecto y el equipo autorizado del canal.

9. Cambios en esta política

Si cambia la forma en que se tratan los datos, se actualizará esta página con una nueva fecha de revisión.

10. Contacto

ONETAKEMUSIK@gmail.com

Privacy policy

Last updated: November 8, 2026

This policy explains how the ADAN Metrics Panel application (the "application") accesses, uses and stores data, including data obtained from Google APIs.

1. Who is behind it

The application is a personal project by Napo, developed in the Dominican Republic, for managing the YouTube channel of the artist ADAN. Data controller and contact: ONETAKEMUSIK@gmail.com.

2. Data we access

The application only requests the permissions needed to read statistics, always read-only:

SourceWhat is read
YouTube Analytics API With the yt-analytics.readonly scope: views, watch time, audience retention, traffic sources, countries, age, gender, subscribers gained and lost, and breakdown by content type (videos and Shorts).
YouTube Data API v3 Public channel and video data: title, publish date, duration, views, likes and comments. No private viewer data is accessed.

The application does not access passwords, emails, contacts, messages, files, calendar or any other Google account information. It never modifies the channel: it does not publish, edit or delete content.

3. How it is used

  • To produce internal reports and growth charts for the channel itself.
  • To generate content and collaboration recommendations for the artist's team.
  • To send periodic summaries to the team via Telegram, when requested.

The data is not used for advertising, commercial profiling, or training artificial intelligence models.

4. Where it is stored

Data is stored only on the controller's own computer, in a SQLite database inside a local Docker container. It is not sent to our own servers, not hosted in the cloud, and not uploaded to any public repository. Google credentials are also stored on that same machine, in a local configuration file excluded from any public copy.

Hourly metric snapshots are kept for 45 days; after that, one snapshot per day is kept. You can delete everything at any time by removing the Docker data volume on that machine.

5. Who it is shared with

It is never sold, rented or shared with third parties. It is not used for advertising or to build user profiles.

The only data leaving the machine is the summary the controller explicitly requests from the Telegram bot, and it is sent only to the team's own chats on that bot's allow-list (a small number of people managing the channel).

6. Security

The dashboard is only reachable from the local machine (local network, with an optional password), the bot rejects any unauthorized chat, and keys are kept out of the source code and out of public repositories.

7. How to revoke access and delete data

  • Revoke the application's permission at any time at myaccount.google.com/permissions. The application immediately loses the ability to read channel data.
  • Request deletion of stored data by writing to ONETAKEMUSIK@gmail.com. Data is deleted within 30 days at most.

8. Limited Use of Google data

ADAN Metrics Panel's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically: Google data is used only for the features described in this policy, it is not sold to third parties, not used for advertising, not used to determine creditworthiness or for lending purposes, and no one can read it except the project owner and the channel's authorized team.

9. Changes to this policy

If the way data is handled changes, this page will be updated with a new revision date.

10. Contact
